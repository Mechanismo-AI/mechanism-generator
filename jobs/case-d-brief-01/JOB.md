## The between-points channel

The demand is a continuous path sampled at pinned points, so the
scorecard carries a between-points channel: max deviation over the
intervals, consuming the per-sample emission machinery (PR-B, schema
v3) natively so per-seed reporting and the interval channel come for
free. The interval channel is measured at a grid refinement of 8x
the native grid, frozen here, with the sampling-honesty convention
attached: SAMPLED, NEVER CERTIFIED (the case B record's own finding
-- between-sample peak 1.47x the at-sample baseline -- is precisely
about sampling density; the refinement is declared before the run so
the channel's worst-case reading is not an artifact of where the
refinement happened to land).

## The failure digest (the analytic at-bat, FIRST)

The digest runs FIRST, before any learned supplier is measured; in a
no-ground-truth family its finds are the training corpus's only
honest source. Its cost accounting counts TWICE (the analytic grade
AND the data-generation cost), recorded supplier-version-scoped; the
freeze declares which numbers feed which.

FAIRNESS GATE (the critic's delta 1, substantive): the digest's
search configuration IS the analytic baseline -- the endgame's core
lesson (a head-to-head is only as honest as its baseline is strong)
lands on the digest itself. The digest's search protocol (restart
count, evaluation budget, acceptance rule) is pinned as the
strongest reasonable configuration at this freeze, declared with
reasons; and any later warm-start comparison runs the SAME
configuration with only the initialization changed -- the
one-variable discipline applied to the comparison, pre-committed
here rather than rediscovered at the capability step. A weak config
would be the staged-declaration error recommitted one level down.

## The derivation check (brief-freeze, desk-only)

Method: desk-only, read-only over the recorded synthesis precedent
(case B's -05/-06 analytic lineage, B2's representation record);
derivation chain visible end-to-end; no runs; output frozen before
the digest stages. It answers three things:

1. The six-bar's exact-synthesis capacity N for this demand class
   (positions and timing pins counted separately).
2. Whether the C2-class timing program constrains beyond the
   position points.
3. The scoped verdict, in the recorded form: "at N+k pinned points
   with timing, no exact synthesis covers the demand class" --
   NEVER "six-bars lack a closed form" (they have one, for analysis
   and for fewer points; the claim is scoped to the demand class,
   exactly as the no-closed-form claim was scoped at the endgame).

If the derivation is inconclusive at the desk, that is a recorded
finding and the eight-bar trigger's input (i) reads INCONCLUSIVE --
read before staging, never defaulted past.
