# Mechanisms-Inc

Open-source tools for mechanism synthesis, motion generation, and mechanically synchronized automation.

## Status

Early development / alpha.

The initial implementation focuses on planar four-bar mechanism synthesis, physics-based refinement, and portfolio generation.

## Project Goals

- Open-source mechanism synthesis tools
- Open model weights
- Motion/path specification through OMTS
- Multiple candidate mechanisms rather than a single answer
- Support for high-speed synchronized manufacturing automation
- Extensible support for additional mechanism topologies

## Current Work

- Four-bar path synthesis
- Transmission-angle optimization
- Physical feasibility checking
- Pareto portfolio generation
- Open Mechanism Task Specification (OMTS)

More documentation coming soon.
